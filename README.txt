Ma Cave & Mes Fromages - V1

Déposez index.html, manifest.webmanifest et sw.js à la racine d'un dépôt GitHub Pages (ou sur tout hébergement HTTPS).
Ouvrez l'adresse HTTPS sur votre téléphone, puis choisissez « Ajouter à l'écran d'accueil » dans le navigateur.
La bibliothèque et les photos sont conservées dans le stockage local du navigateur. Utilisez régulièrement le bouton « Sauvegarder mes données » : la suppression des données du navigateur peut effacer la bibliothèque.
Cette V1 permet la photo, la saisie manuelle du nom, les 5 pastilles, la recherche, les filtres, la modification et la sauvegarde/restauration. La reconnaissance automatique par IA n'est pas encore intégrée et nécessitera un service sécurisé (ne pas insérer une clé API privée dans le JavaScript public).
